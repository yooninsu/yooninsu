## What I work on

**Deep learning for spectral data**
Training and benchmarking 1D CNNs, Transformers, and self-supervised encoders against classical
baselines, using leakage-aware validation across instruments, batches, and clinical sites.

**End-to-end ML pipelines**
Preprocessing → QC → training → evaluation → inference API, with reproducible experiments
tracked through MLflow and a PostgreSQL experiment store.

**Agentic ML workflows**
Orchestrating experiment flows with LangGraph, and using LLM agents to run, audit, and record
experiments with a human in the loop.

**Model interpretability**
Connecting model decisions to domain signals with SHAP and Grad-CAM.

**Clinical data engineering and regulated ML**
Designing clinical data schemas and integrity checks, and building for SaMD and dGMP requirements:
GAMP5/CSV, IQ/OQ/PQ, and audit trails.
